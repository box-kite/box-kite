# Changelog

The release notes live in [`releases/`](releases/), one file per version, and each is the body of the matching
[GitHub Release](https://github.com/box-kite/box-kite/releases).

| Version                      | Date       | In one line                                                                                                                                                                                                                                                                         |
| ---------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [2.2.17](releases/2.2.17.md) | 2026-11-03 | A checkbox's tick and a radio's dot now follow the theme, a design and Windows High Contrast, where a checked box used to look unchecked — and a closing dialog, popover, menu or date picker keeps its content until its exit has finished.                                        |
| [2.2.16](releases/2.2.16.md) | 2026-11-02 | The published types are whole again, so a misspelt component, variant or value is a type error rather than `any` — and a `ref` on `Form` and fourteen other components no longer breaks them on React 19.                                                                           |
| [2.2.15](releases/2.2.15.md) | 2026-11-02 | `@box-kite/mcp` now finds a prop from a CSS property written in words, or from another library's name for it: "border bottom" and `borderBottom` answer `bb`, `rounded` answers `borderRadius`.                                                                                     |
| [2.2.14](releases/2.2.14.md) | 2026-11-02 | `npm create @box-kite` now sets a new app up for its coding agent with `AGENTS.md`, `CLAUDE.md` and the MCP server, and `npm create @box-kite@latest -- --agents-only` adds the same to an existing project.                                                                        |
| [2.2.13](releases/2.2.13.md) | 2026-10-30 | Hovering a prop inside `Box.components()` now shows its documentation and a measured example, the way it does on `<Box>`.                                                                                                                                                           |
| [2.2.12](releases/2.2.12.md) | 2026-10-29 | In Safari, a menu or a date picker that opened above its trigger now stays there while it closes, instead of blinking below it.                                                                                                                                                     |
| [2.2.11](releases/2.2.11.md) | 2026-10-29 | In Safari, a date picker, a popover or a menu opened near the bottom of the screen now appears above its trigger at once, instead of opening below it and jumping.                                                                                                                  |
| [2.2.10](releases/2.2.10.md) | 2026-10-28 | A date picker offers only the times within `min` and `max`, its panel can be as wide as a stretched field, and `pickOnly` turns the field into one button for a short list where typing adds nothing.                                                                               |
| [2.2.9](releases/2.2.9.md)   | 2026-10-28 | A date picker stretched across a form keeps its clock or calendar button at the end of the field.                                                                                                                                                                                   |
| [2.2.8](releases/2.2.8.md)   | 2026-10-28 | Every interaction on the page in one typed stream, `Box.onInteraction`, and `@box-kite/react/analytics` to send it somewhere with a session on every record, while an app that never listens pays for one comparison.                                                               |
| [2.2.7](releases/2.2.7.md)   | 2026-10-19 | A second design for the same app, chosen in CSS: `Box.components(styles, { design })`, two colour families every component is drawn in, and `Box.useDesign()` to switch between them — plus `npm create @box-kite`, which starts a Vite app with one of four designs already in it. |
| [2.2.6](releases/2.2.6.md)   | 2026-10-19 | Dates, times and time zones: a date layer with no dependency, where a value is an ISO string whose shape says what it is, and a field, a calendar, date and range pickers and a time zone select built on it.                                                                       |
| [2.2.5](releases/2.2.5.md)   | 2026-10-17 | Lists, for the screens that are mostly lists: `<List>`, with swipe actions, drag to reorder and a windowed list on top of it, and a DataGrid that becomes one on a phone.                                                                                                           |
| [2.2.4](releases/2.2.4.md)   | 2026-10-13 | A Server Component page no longer sends the base stylesheet once per Box.                                                                                                                                                                                                           |
| [2.2.3](releases/2.2.3.md)   | 2026-10-13 | Box Kite is the only name the package carries.                                                                                                                                                                                                                                      |
| [2.2.2](releases/2.2.2.md)   | 2026-10-12 | A theme switch that settles at once on any page, and a DataGrid column chooser you can read.                                                                                                                                                                                        |
| [2.2.1](releases/2.2.1.md)   | 2026-10-09 | The DataGrid header and bottom bar: a hover pill, every word translatable, a selection that survives a filter, and one-frame row ticks.                                                                                                                                             |
| [2.2.0](releases/2.2.0.md)   | 2026-10-08 | Scroll-driven animation and view transitions become props, and a page of Boxes re-renders, hydrates and restyles for a fraction of the cost.                                                                                                                                        |
| [2.1.0](releases/2.1.0.md)   | 2026-09-21 | A model can compose the UI, the app still owns it, and the data grid becomes a spreadsheet.                                                                                                                                                                                         |
| [2.0.1](releases/2.0.1.md)   | 2026-09-17 | The release pipeline publishes to npm again, and signs what it publishes.                                                                                                                                                                                                           |
| [2.0.0](releases/2.0.0.md)   | 2026-09-16 | Every floating layer moves onto the browser’s own, and the package teaches the agent writing the code.                                                                                                                                                                              |
| [1.0.0](releases/1.0.0.md)   | 2026-09-04 | The library becomes Box Kite, and the engine becomes a package.                                                                                                                                                                                                                     |
