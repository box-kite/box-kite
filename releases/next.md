# Box Kite next

_Unreleased. A PR that changes what a consumer sees adds its section here — see CONTRIBUTING.md, "Release notes"._

Box Kite is the only name the package carries. The README on npm no longer points back to the library's old name, and nothing in the code changed.

## Highlights

- **[One name](#one-name)** — the README, the changelog and the release notes speak of Box Kite and nothing else.

## One name

The package page on npm still opened with a note about the name the library had before 1.0.0. That note is gone, and so is the compatibility package it pointed to, which has been deprecated since 1.0.0 and receives no further versions. If you install `@box-kite/react` and `@box-kite/core`, nothing changes for you: the code in this release is the code in 2.2.2.

The [1.0.0 notes](https://github.com/box-kite/box-kite/blob/main/releases/1.0.0.md#the-packages) now say what each package is rather than what it used to be called, and they still say where type augmentation points (`@box-kite/core/types`).
