# Box Kite 2.2.13

_30 October 2026 · [npm](https://www.npmjs.com/package/@box-kite/react) · [Compare v2.2.12...v2.2.13](https://github.com/box-kite/box-kite/compare/v2.2.12...v2.2.13)_

Hovering a prop inside `Box.components()` now shows its documentation and a measured example, the way it does on `<Box>`.

## Breaking changes

None.

## Fixes

- **Hovering a prop inside `Box.components()` or `Box.createComponents()` showed its type and no documentation.** It now shows the same description and measured example a prop on `<Box>` does — in `styles`, in every variant and in a child at any depth.
